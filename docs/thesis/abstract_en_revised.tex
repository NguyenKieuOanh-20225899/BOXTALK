\section*{Abstract}

This thesis studies methods for extracting, indexing, retrieving, and answering
questions over PDF documents. The main focus is not only to generate an answer,
but also to preserve the structure and source information of the original PDF so
that the answer can be verified. The proposed system is organized into two
connected workflows. The ingest workflow analyzes PDF pages, routes content
regions, extracts text, reconstructs tables, and stores source metadata. The query
workflow builds retrieval indexes from the extracted data, retrieves evidence,
checks whether the evidence is sufficient, generates an answer, and returns source
citations.

The system combines keyword retrieval, dense retrieval, hybrid retrieval, and
retrieval-augmented question answering. For tables, the thesis evaluates default
table extraction, Table Transformer, and a Hybrid TATR design that combines
table geometry with word boxes from the PDF text layer. The experiments are
conducted at multiple levels, including PDF ingest, layout and OCR components,
table reconstruction, retrieval, table-aware chunking, grounded question answering,
and ablation studies.

Experimental results on the QCDT benchmark show that the proposed pipeline can
retrieve relevant evidence and generate citation-grounded answers within the
evaluated settings. However, the results on QASPER indicate that the system
remains limited for long scientific documents and questions requiring
multi-evidence synthesis.
